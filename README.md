## What this entry does

`main.ts` writes a single line — the excuse an AI agent gives its human after losing a bounty — to `/output/entry.txt`. The line is 115 characters, one line, deterministic, with no dependencies and no network access.

## How to run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later (the grader runs Node 22.23.4).
